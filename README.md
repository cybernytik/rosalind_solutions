# Решения задач Rosalind

Добро пожаловать! 
Этот репозиторий создан для совместной работы над задачами с платформы [Rosalind](http://rosalind.info/).
Здесь мы собираем наши решения, учимся работать с GitHub, а также помогаем друг другу.

## Структура репозитория

- Каждая задача лежит в отдельной папке.
- Название папки: `task_ID`, где ID - код решаемой задачи (например, task_prot или task_dna)
- Внутри папки: файл с решением (например, `rosalind_ID.py` или `rosalind_ID.ipynb`) и описание с кратким пояснением, чтобы можно было увидеть ход ваших мыслей.

## Как сдать задачу?

**NB**: Мы не пушим напрямую в `main`! 
Работаем через ветки и `Pull Request`.

### Шаг 1: Подготовка (делается один раз)
1. Установите Git и создайте аккаунт на GitHub.
2. Сделайте **Fork** этого репозитория (кнопка `Fork` в правом верхнем углу). Это создаст вашу личную копию.
3. Клонируйте **свой форк** на компьютер:
   ```bash
   git clone https://github.com/ваш_ник/rosalind_solutions.git
   cd rosalind_solutions
4. настройте связь с оригиналом:
   ```bash
   git remote add upstream https://github.com/cybernytik/rosalind_solutions.git

### Шаг 2: Создание ветки для вашей новой задачи
1. Переключитесь на `main` и обновите его
   ```bash
   git checkout main
   git pull upstream main

3. Создайте новую ветку (называйте своим ником)
   ```bash
   git checkout -b task_ваш_ник

### Шаг 3: Непосредственно работа и коммит
1. Создайте папку `task_ID` (по ID задачи) и сохраните в ней файл `rosalind_ID.py`.
   ```bash
   mkdir task_ID
   cd task_ID
   touch rosalind_ID.py
   cd ..
2. Сохраните изменения.
3. Закоммитьте:
   ```bash
   git add task_ID
   git commit -m "Решение задачи DNA: подсчет нуклеотидов" (как пример)

### Шаг 4: Push и Pull Request
1. Отправьте ветку в свой форк:
     ```bash
     git push origin task_DNA

2. Зайдите на GitHub в свой форк. Вы увидите кнопку `Compare & pull request` (зеленая). Нажмите её.

   **Важно**: убедитесь, что стрелка идет из вашего task_DNA в `main` оригинального репозитория (base repository).

4. Напишите заголовок и нажмите `Create pull request`.


## FAQ
- *почему это полезно?*

  **Rosalind** - это практическая площадка для изучения биоинформатики через решение реальных вычислительных задач, взятых из молекулярной биологии. Польза в том, что вы не просто читаете теорию, а сразу применяете её на практике: пишете код, который обрабатывает биологические данные. Задачи построены по принципу возрастающей сложности (от простых манипуляций со строками до реализации сложных алгоритмов), а сайт автоматически проверяет ответ.
---
- *обязательно ли создавать свой аккаунт на Rosalind?*

  Весь прогресс и проверка решений на Rosalind привязаны к вашему аккаунту. **Задачи действительно можно читать и без входа**, но чтобы отправить ответ на проверку и получить следующий набор данных, или ваш dataset, система должна знать, кто именно решает задачу. Так же **без регистрации вы не сможете узнать, правильное ли вы решили задачу** (так как автоматическая проверка работает только для авторизованных пользователей) и **сохранить историю своих решений и отследить прогресс**. Аккаунт - это ваш личный пропуск в систему, которая запоминает, какие задачи вы уже сдали.
---
- *что делать, если вас попросили внести правки в решение (например, если код не запускается)*

  1. Внесите правки в файлы в той же ветке (task_DNA).
  2. Сделайте коммит и пуш:
       ```bash
       git add .
       git commit -m "Исправление: добавлена обработка ошибок"
       git push origin task_DNA
  PR обновится автоматически. Новый PR создавать не нужно.
