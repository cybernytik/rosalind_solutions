# Решения задач Rosalind

Добро пожаловать! 
Этот репозиторий создан для совместной работы над задачами с платформы [Rosalind](http://rosalind.info/).
Здесь мы собираем наши решения, учимся работать с GitHub, а также помогаем друг другу.

## Структура репозитория

- Каждая задача лежит в отдельной папке.
- Название папки: `problem_ID`, где ID - код решаемой задачи (например, rosalind_prot или rosalind_dna)
- Внутри папки: файл с решением (например, `solution_ID.py` или `solution_ID.ipynb`) и файл `README.md` с кратким пояснением, чтобы можно было увидеть ход ваших мыслей.

## Как сдать задачу?

NB: Мы не пушим напрямую в `main`! Работаем через ветки и Pull Request.

### Шаг 1: Подготовка (делается один раз)
1. Установите Git и создайте аккаунт на GitHub.
2. Сделайте **Fork** этого репозитория (кнопка `Fork` в правом верхнем углу). Это создаст вашу личную копию.
3. Клонируйте **свой форк** на компьютер:
   ```bash
   git clone https://github.com/ваш_ник/rosalind_solutions.git
   cd rosalind_solutions
4. настройте связь с оригиналом:
   git remote add upstream https://github.com/cybernytik/rosalind-solutions.git

### Шаг 2: Создание ветки для вашей новой задачи
1. Переключитесь на main и обновите его
  git checkout main
  git pull upstream main

2. Создайте новую ветку (называйте по ID задачи)
  git checkout -b task_ID

### Шаг 3: Непосредственно работа и коммит
1. Создайте папку problem_DNA и сохраните в ней файл solution_ID.py.
2. Сохраните изменения.
3. Закоммитьте:
   ```bash
     git add .
     git commit -m "Решение задачи DNA: подсчет нуклеотидов" (как пример)

### Шаг 4: Push и Pull Request
1. Отправьте ветку в свой форк:
  ```bash
     git push origin task_DNA

2. Зайдите на GitHub в свой форк. Вы увидите кнопку Compare & pull request (зеленая). Нажмите её.
  **Важно**: убедитесь, что стрелка идет из вашего task_DNA в main оригинального репозитория (base repository).

3. Напишите заголовок и нажмите Create pull request.


## FAQ
- почему это полезно?

- что делать, если вас попросили внести правки в решение (например, если код не запускается)
  1. Внесите правки в файлы в той же ветке (task_DNA).
  2. Сделайте коммит и пуш:
    ```bash
       git add .
       git commit -m "Исправление: добавлена обработка ошибок"
       git push origin task_DNA
  PR обновится автоматически. Новый PR создавать не нужно.
